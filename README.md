# 🌍 EcoMap - Cidades Limpas, Consciência Ativa

> Plataforma digital para mapeamento e denúncia de descarte irregular de lixo urbano.
## 💻 Sobre o Projeto

O **EcoMap** é um sistema web desenvolvido como Trabalho Final da disciplina de Atividade Extensionista II do curso de CST em Análise e Desenvolvimento de Sistemas. 

O objetivo principal da plataforma é combater o descarte irregular de resíduos no município de Santa Maria - RS, permitindo que a comunidade local registre denúncias geolocalizadas, anexem fotos e acompanhem os pontos críticos da cidade através de um mapa interativo.

## ⚙️ Funcionalidades

- **Registro de Denúncias:** Usuários podem reportar focos de lixo informando a gravidade, descrição e adicionando fotos do local.
- **Geolocalização:** Integração com mapas para marcar o ponto exato da ocorrência.
- **Filtros Interativos:** Visualização das denúncias no mapa com filtros por nível de gravidade (Baixa, Média, Alta).
- **Engajamento Comunitário:** Sistema de comentários nas denúncias e ranking de usuários mais engajados.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

* **Frontend:** HTML5, CSS3 (`style.css`), e JavaScript (`app.js`)
* **Backend:** Node.js (`server.js`)

## 🚀 Como Executar o Projeto

### Pré-requisitos
Antes de começar, você vai precisar ter instalado em sua máquina o [Git](https://git-scm.com) e o [Node.js](https://nodejs.org/en/).

### Rodando a Aplicação localmente

```bash
# Clone este repositório
$ git clone [https://github.com/SEU-USUARIO/ecomap.git](https://github.com/SEU-USUARIO/ecomap.git)

# Acesse a pasta do projeto no terminal/cmd
$ cd ecomap

# Instale as dependências do Node (caso utilize o Express ou outras bibliotecas)
$ npm install

# Inicie o servidor
$ node server.js

# O servidor inciará na porta padrão (ex: 3000) - acesse http://localhost:3000 no navegador
```
